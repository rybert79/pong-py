# Pong Game 🏓

A simple Pong game built with **Python** and **Pygame** as a learning project.

This project is part of my journey learning game development with Pygame, object-oriented programming (OOP), and basic game physics.

## Features

- Two-player gameplay
- Keyboard-controlled paddles
- Ball movement using delta time
- Ball collision detection with paddles
- Wall collision detection
- Automatic winner detection
- Paddle boundary constraints

## Controls

| Player   | Move Up | Move Down |
| -------- | ------- | --------- |
| Player 1 | `W`     | `S`       |
| Player 2 | `E`     | `D`       |

## Requirements

- Python 3
- Pygame

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/rybert79/YOUR_REPOSITORY.git
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR_REPOSITORY
   ```

3. Install Pygame:

   ```bash
   pip install pygame-ce
   ```

4. Run the game:

   ```bash
   python3 main.py
   ```
